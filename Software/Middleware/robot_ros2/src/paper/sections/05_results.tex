\section{Results and Diagnostic Data}

A comprehensive diagnostic pipeline continuously broadcasts
internal controller states across a structured topic hierarchy
to objectively quantify algorithmic performance. Data is presented
separately for the static home posture and dynamic trotting gait.

\subsection{Static Home Posture Stabilization}

During the static home posture, the quadruped maintains all four
limbs in ground contact while the PID controller actively
rejects base orientation disturbances.

Fig.~\ref{fig:home_results} presents the pitch and roll 
error tracking response. The orientation error steadily converges to zero,
confirming that the deadband and integral anti-windup mechanisms
effectively stabilize the system. The integrated multistage pipeline
produces appropriate actuator commands suitable for sustained balancing
without triggering unwanted oscillations around the setpoint.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=\columnwidth]{figures/pid_error_home.png}
    \caption{Controller error response during static home posture}
    \label{fig:home_results}
\end{figure}

\subsection{Dynamic Trotting Gait Stabilization}

During active trotting locomotion, the adaptive PID controller
maintains postural stability while the quadruped executes cyclic
quintic trajectories.

Fig.~\ref{fig:trot_results} displays the dynamic pitch and roll
error during the trotting phase. Despite the periodic ground impact
forces inherent to legged locomotion, the adaptive mechanisms correctly
extract the sustained tilt trend from cyclic gait artifacts. 
This response successfully mitigates external dynamic shifts and prevents 
long-term drift accumulation, ensuring steady continuous locomotion.

    \caption{Controller error response during dynamic trotting gait}
