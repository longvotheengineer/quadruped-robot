\section{Conclusion and Future Work}

This paper presented a robust posture stabilization and motion generation framework for a custom quadruped robot. By decoupling the trajectory planning from the balance control logic, the proposed system achieves high responsiveness and stability. The implementation of quintic foot trajectories ensures smooth kinematic transitions and minimizes structural impact. Furthermore, integrating a multistage IMU processing pipeline—featuring dynamic deadband suppression and adaptive PID regulation—reliably counters external disturbances during both static standing and dynamic locomotion. The experimental validation confirmed that the framework efficiently handles orientation corrections continuously in a real-time ROS~2 environment without relying on monolithic or computationally expensive optimizers.

Future work will focus on the following core areas:
\begin{enumerate}
    \item Advancing state estimation by dynamically fusing localized joint encoder readings with IMU kinematics to track global deformations and deviations.
    \item Expanding the trajectory generation module to support variable walking speeds and continuous adaptive stride length modulation for uneven terrain.
    \item Replacing the current deterministic gain scheduling strategy with optimal control methods, such as Model Predictive Control (MPC), to anticipate and compensate for larger rotational disturbances proactively.
\end{enumerate}
